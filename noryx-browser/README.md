# NORYX Browser v0.1.0

Standalone Android WebView browser. No AI, chatbot, HYPERSYNTH, cloud, accounts, scraping, tracking or telemetry.

Package: `com.noryx.browser`

Stack: Kotlin, Android XML Views, ViewBinding, WebView.

Security baseline: INTERNET only; HTTPS-first input normalization; cleartext HTTP disabled; JavaScript and DOM storage enabled; file/content access disabled; mixed content disabled; no JavaScript interfaces.
